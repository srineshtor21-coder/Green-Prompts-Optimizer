Install Chrome Extension

Coming soon to Chrome Web Store. For now, load it manually in under 2 minutes.

1
Download the extension

Download ZIP from GitHub and extract it anywhere on your computer.

2
Find the chrome-extension folder

Inside the extracted ZIP, look for the chrome-extension folder.

3
Open Chrome Extensions

Go to chrome://extensions/ in your browser address bar.

4
Enable Developer Mode

Toggle the switch in the top-right corner of the extensions page.

5
Load the extension

Click "Load unpacked" and select the chrome-extension folder.

6
Start optimizing

Visit ChatGPT, Claude, or any AI platform. Click the extension icon to optimize any prompt instantly.
